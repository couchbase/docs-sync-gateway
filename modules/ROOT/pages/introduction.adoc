== Sync Gateway
Sync Gateway is a secure, high-performance gateway designed for cloud-to-edge data synchronization.
It serves as the synchronization server in a Couchbase Mobile deployment, enabling mobile, web, and IoT applications to view and sync data with Couchbase Server.

You can use Sync Gateway in conjunction with Couchbase Lite for full bi-directional sync between edge devices and the cloud.
It provides fine-grained access control, RESTful API, and secure sync capabilities.

++++
<div class="card-row">
++++

[.column]
==== Why Use Sync Gateway?

* _Bi-directional synchronization_: Sync data between Couchbase Lite clients and Couchbase Server.
* _Secure access control_: Supports RBAC, channels, and sync functions.
* _RESTful API_: Public, Admin and Metric RESTAPI for data and configuration access.
* _Scalable architecture_: Designed for high-throughput, cloud-to-edge synchronization.

[.column]
==== Key Capabilities

* Fine-grained data routing with channels.
* Sync Function for customizable business logic.
* Role- and user-based access control.
* Integration with Couchbase Lite and Couchbase Server.
* Supports peer-to-peer, cloud, and hybrid sync topologies.

| Prepare Your Environment
| xref:get-started-prepare.adoc#configure-server[create a bucket], xref:get-started-prepare.adoc#step-2create-rbac-user[configure RBAC users], and xref:get-started-prepare.adoc#lbl-set-netw-access[verify network access].

| Install Sync Gateway
| Follow platform-specific steps to install and configure Sync Gateway on xref:get-started-install.adoc#install-for-linux[Linux], xref:get-started-install.adoc#install-for-windows[Windows], or xref:get-started-install.adoc#install-for-mac-os[Mac OS], and xref:get-started-install.adoc#check-the-install[confirm installation].

| Sync Gateway Configuration
| Understand xref:configuration-schema-bootstrap.adoc[bootstrap configuration], using xref:configuration-javascript-functions.adoc[JavaScript functions], xref:configuration-schema-isgr.adoc[inter-gateway replication], and xref:configuration-schema-db-security.adoc[database security] configurations.

| Data Synchronization
| Configure xref:sync-with-couchbase-server.adoc[sync with Couchbase Server], xref:sync-using-app.adoc[mobile applications], xref:sync-inter-syncgateway-overview.adoc[inter-gateway replication], xref:delta-sync.adoc[delta sync] optimization, and xref:import-processing.adoc[import processing] for non-Sync Gateway changes.

| Interact with Sync Gateway programmatically via its xref:rest-api-admin.adoc[Admin], xref:rest-api-metrics.adoc[Metrics] and xref:rest-api.adoc[Public] REST API interfaces.
