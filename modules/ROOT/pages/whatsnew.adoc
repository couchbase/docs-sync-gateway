include::partial$block-caveats.adoc[tags=eventing-mixed-mode]

Do not deploy Eventing/Sync Gateway until all SGW nodes are at version 3.2+.
For earlier Sync Gateway versions that do not write import XATTRs, Eventing functions may encounter infinite recursions and duplicate mutations if deployed in a mixed mode SGW environment.
This occurs if you have a mixed installation consisting of Sync Gateway 3.2 and an earlier version, and you deploy a new Eventing or Sync Gateway function during an upgrade.
